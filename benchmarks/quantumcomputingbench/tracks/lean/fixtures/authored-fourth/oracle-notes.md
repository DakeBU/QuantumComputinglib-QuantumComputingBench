## BE101: a small exact loader calibration

The loader acts on the eight three-bit slots by XOR with the mask `011`.
The image list is `[3,2,1,0,7,6,5,4]`, and XOR with the same mask twice restores
the input. The literal two-X prefix of the actual seven-wire source witness
also realizes this low-three-bit action and restores every seven-wire basis
label when repeated. The latter statement leaves the four spectator wires
arbitrary. It does not execute the modular adder or claim clean-work arithmetic.

The mathematical explanation uses the cancellation identity
`(s XOR 3) XOR 3 = s` and commuting flips of distinct low bits. The authored
formal reference instead uses disclosed finite kernel decision. In particular,
the complete fixed root is decidable in one call once the definitions are
available. It should be reported as a small finite calibration, even when the
course uses its three subclaims to teach statement reading and register order.
Its construction band must not imply nontrivial proof search.

The production table theorem uses a native-generated axiom outside the fixed
benchmark policy. The authored equality is rechecked by kernel decision and
does not call that theorem. This policy-specific distinction is neither a
refutation of the source theorem nor whole-module trust clearance.

## BE104: compiler induction with a phase-sensitive refutation

There are independent reversible-bijection and primitive-matrix denotations.
Chronological composition places later matrices on the left. Gate-case compiler
soundness plus list induction proves the full program equality
`D = exp(i phi) C = P(E)`. The supplied construction rebuilds that induction;
the imported exact compiler theorem remains callable and is disclosed as a
shortcut. The general width theorem specializes to the seven-wire question;
it does not generalize the source adder's arithmetic or resource claims.

The exact compiled angle fields sum to `45*pi/8` for the actual witness. This
is an evaluated exact angle, rather than an automatically phase-reduced
representation. For the positive reference, `exp(i*45*pi/8) = 1` would force
`45/16` to be an integer. Taking the imaginary part of the complex exponential
period identity puts that integer strictly between 2 and 3, a contradiction.
An entry of `P(E)` on its permutation support is exactly one; it therefore
witnesses that the bare list matrix cannot equal `P(E)`.

The six supplied obligations join general compiler soundness, the exact ledger,
the inverse-phase bare formula, nontrivial phase and the actual refutation.
This is a meaningful induction and phase-bookkeeping construction route, not
a guarantee that a model must rediscover the source gate compiler or use the
same proof method. The references do not kernel-check the entire prose account
of H/T/Tdagger counts, the normalized factor `exp(3*pi*i/8)`, or a physical
controlled implementation. Those remain explicit canonical rubric obligations.
The actual source phase is retained; the historical false bare equality is
never restored by redefining `C`.

## BE120: invariant, involution and a boundary counterexample

The source image flips one indicator bit according to a predicate on separate
system bits. The system value, hence the predicate, is unchanged by the first
flip. The second application therefore XORs the same mask and cancels it.
This gives involution on every natural label. The source bound permits the
same function on the finite register; involution supplies both injectivity and
surjectivity. The authored construction uses those mechanisms explicitly.

The source certificate also makes the stored dagger slot's matrix field equal
to the forward slot. This is a literal record-field equality in the symbolic
`Coeff` language. The formal root does not turn that syntax into a theorem
about complex-matrix multiplication or a physical adjoint. In a standard
permutation-matrix interpretation, label involution is the relevant condition
for using the same map to undo itself; an actual Hilbert-space adapter and
ancillary-state interpretation are additional obligations.

The finite counterexample is the cyclic equivalence `i -> i+1` on `Fin 3`.
It is bijective but its second application sends 0 to 2. Thus a permutation
need not be an involution. This is a mathematical counterexample to a general
inference, not a failure of the source warm instance or an ill-typed proof
used as a negative verifier control.

## Evidence and continuation boundaries

It is separate from independent semantic review and from the central fixed-root
protocol receipt. It uses fresh compiler processes per core, not per obligation,
and runs no model output. Positive roots must use only `propext`,
