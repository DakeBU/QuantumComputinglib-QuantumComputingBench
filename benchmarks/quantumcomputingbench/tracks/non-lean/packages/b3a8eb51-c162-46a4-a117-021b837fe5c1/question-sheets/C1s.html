When may a phase gate cross a permutation?

Assumptions

  • Let XX be a finite nonempty set with orthonormal basis {|x⟩:x∈X}\{|x\rangle:x\in X\}. For a permutation pp of XX and a function a:X→𝕋a:X\to\mathbb T, write M(a,p)|x⟩=a(x)|p(x)⟩M(a,p)|x\rangle=a(x)|p(x)\rangle, where 𝕋={z∈ℂ:|z|=1}\mathbb T=\{z\in\mathbb C:|z|=1\}.
  • Write Pp=M(1,p)P_p=M(1,p) for pure routing and Df=M(f,id)D_f=M(f,\mathrm{id}) for a phase table f:X→𝕋f:X\to\mathbb T.

Conventions

  • Kets are columns. The rightmost factor acts first. Rows label outputs, and columns label inputs. Two operators agree up to global phase when one is a single constant of modulus one times the other on all inputs.

Question

Determine the output label and amplitude of M(b,q)M(a,p)|x⟩M(b,q)M(a,p)|x\rangle for arbitrary weights and permutations. A circuit designer wants to move a phase gate to the input side of a routing gate. Determine the unique table gg satisfying DfPp=PpDgD_fP_p=P_pD_g. When does keeping the original table give exact equality? When does keeping it give equality up to a single global phase? Prove both tests.

As a wiring check, let X={0,1}2X=\{0,1\}^2, write a label as (c,t)(c,t) with control bit first, and take p(c,t)=(c,t⊕c)p(c,t)=(c,t\mathbin{\oplus}c) and f(c,t)=eiθtf(c,t)=e^{i\theta t} for real θ\theta. Give the corrected input-side table and determine every angle for which the uncorrected reordering is valid, both exactly and up to a global phase. At θ=π\theta=\pi, give a normalized two-term input for which the two uncorrected orderings produce orthogonal states, even though their computational-basis output probabilities agree on each computational-basis input.
