# Unadmitted out-of-snapshot material

No out-of-snapshot question draft is included in this cohort. All active proposal
anchors must belong to the frozen benchmark snapshot. No live-library node or
new mathematical theorem is inserted into that snapshot by these NL proposals.

For a future target whose required live node is absent, retain its draft here
with `admission: unadmitted_snapshot_refresh_required`, exact source commit,
file/declaration/hash, proposed graph identity and substantive mathematical
scope. Submit a separate refresh request identifying the old snapshot and the
requested generated/reviewed successor. Keep its unknown IDs out of active
`proposals/*.json` until a maintainer admits that snapshot. A nearby compiled
node or a planned conceptual transport does not substitute for the missing
interface.

The next-cohort backlog distinguishes source-supported mathematics from planned
work and lists the source/access checks needed before drafting those questions.
